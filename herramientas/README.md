# Herramientas

Scripts en Python que generan el catálogo de recorridos reales a partir del registro del Ministerio de Transportes y de las calles de OpenStreetMap. No se ejecutan en el servidor: su resultado son los SQL de `bd/postgres/inicio/05` y `06`.

**Responsable:** Benjamín Muñoz. Revisa: Benjamín Cuevas.

Uso, fuentes y exclusión de datos personales: [`docs/catalogo-recorridos.md`](../docs/catalogo-recorridos.md).
