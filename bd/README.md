# Bases de datos

**Responsable:** Benjamín Muñoz. Revisa: Benjamín Cuevas.

| Carpeta | Contenido |
|---|---|
| `postgres/inicio/` | Se ejecutan en orden la primera vez que se crea la base: `01` esquema (15 tablas), `02` datos de prueba ficticios (trazado 9001), `03` cuenta de la API con permisos mínimos, `04` a `06` catálogo de recorridos reales |
| `postgres/pruebas_integridad.sql` | Comprueba restricciones CHECK, UNIQUE y claves foráneas |
| `mongo/` | Colecciones con validadores, índices con caducidad y cuenta de la API |

El catálogo se explica en [`docs/catalogo-recorridos.md`](../docs/catalogo-recorridos.md).
